# Отчет о проделанной работе по frontend

## Базовая реализация

- В качестве основного стека использованы:
  - `Next.js`;
  - `React`;
  - `TypeScript`;
  - `Tailwind CSS`.
- Настроена маршрутизация приложения на базе App Router.
- Сформирована модульная архитектура frontend-проекта.
- Кодовая база разделена на логические слои:
  - страницы приложения;
  - переиспользуемые UI-компоненты;
  - feature-модули;
  - API-слой;
  - общие утилиты и типы.
- Настроены команды для разработки, сборки, линтинга и тестирования.
- Подготовлена production-сборка приложения.
- Настроен Dockerfile для контейнеризации frontend.
- Подготовлен `docker-compose.yml` для локального и демонстрационного запуска.
- Настроена работа с переменными окружения через `.env.example`.
- Реализовано проксирование API-запросов frontend на backend.

## Архитектура и API-интеграция

- Реализован централизованный API-клиент.
- Вынесена логика HTTP-запросов из UI-компонентов.
- API-методы сгруппированы по функциональным модулям.
- Описаны frontend DTO для обмена данными с backend.
- Реализована единая обработка успешных и ошибочных API-ответов.
- Реализовано преобразование технических ошибок backend в понятные пользовательские сообщения.
- Внедрена типизация API-контракта.
- Подготовлена архитектура для синхронизации frontend-типов с OpenAPI.
- Внедрена runtime-валидация критичных API-ответов.
- Реализована защита от некорректных или неожиданных данных backend.
- Введен единый слой маршрутов приложения.

## Авторизация и безопасность

- Реализована регистрация пользователей.
- Реализован вход по email и паролю.
- Реализован OAuth-сценарий входа через VK.
- Реализован callback-обработчик для внешней авторизации.
- Access token хранится в памяти приложения.
- Refresh token обрабатывается через cookie.
- Реализовано автоматическое обновление access token.
- Реализован повтор исходного запроса после успешного refresh.
- Реализована защита от параллельных refresh-запросов.
- Реализован клиентский logout.
- Реализован server-side logout через backend endpoint.
- Реализован отзыв refresh-сессии при выходе пользователя.
- Реализована синхронизация logout между вкладками.
- Формализована модель состояния авторизации.
- Реализована защита маршрутов по ролям.
- Поддержаны роли:
  - `participant`;
  - `stander`;
  - `admin`.
- Реализована проверка доступа к защищенным разделам.
- Реализована обработка сценариев истечения сессии.
- Подготовлена CSRF-совместимая отправка небезопасных запросов.
